# Private provider-backed risk check

This workflow is for the exact private test preview only. It defaults to disabled and requires `RACK_RELIC_TEST_RISK_CHECK_ENABLED=true` plus the existing explicit operator and staging-member configuration. Production, other preview branches and ordinary members cannot use it. No new database tables, grants or credentials are needed.

The operator sends only an order reference. The backend checks current membership and participant access, loads the trusted paid order, verifies the fixed Stripe sandbox account and test balance, and retrieves the matching PaymentIntent and captured charge. Amount, currency, metadata, transfer group, payment identity and platform-only charge shape must agree. A provider review is fetched separately and bound to the same test charge. Cached, foreign, live-mode and malformed evidence is rejected. Provider data and credentials are never returned to the browser.

The existing conservative evaluator derives the result. Successful issuer authorization alone cannot clear missing or unsuccessful 3DS, failed AVS/CVC, refunds, unresolved provider reviews or dispute indicators. No browser-supplied risk score, decision, charge ID or assessment is accepted. Operator access and order participation are checked again immediately before saving. Existing database freshness requirements and sticky manual-review/blocked holds remain authoritative; refreshing cannot silently override them. A clear result may move the existing test shipping job to pending review, but this action does not purchase a label, send a seller notification or create a payout.

The browser action is manual, duplicate-click guarded and authenticated. Late responses cannot restore orders or notes after sign-out. No customer email or card details are included in the request. Financial actions and label generation remain separate workflows. This test control does not establish production fraud operations, dispute handling or guaranteed card ownership/liability shift.

The preceding USPS acceptance passed with an authenticated $35.59 synthetic purchase, one free marked sample label, a full provider-confirmed refund and balanced signed accounting. That run used a fresh evaluator-derived assessment recorded through the backend database function. This private control replaces that manual evidence-entry step; deployed acceptance is still required after publication and explicit preview activation.
